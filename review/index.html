Keyboard shortcuts

Ctrl+EnterMark reviewed and go to the next segment
Alt+PPlay the selected segment
Alt+KPlay / pause
Alt+J / LBack / forward 3 seconds
Alt+↑ / ↓Previous / next segment
Alt+SSplit at the text cursor (time: at the playhead)
Alt+MMerge with the next segment
Ctrl+SSave now (it also saves automatically)

Typical flow: press Alt+P, listen, correct the text, press Ctrl+Enter. Verse texts always come from the official Quran data; you only set the references.
